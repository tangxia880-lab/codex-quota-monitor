# Codex 额度监控（蓝紫悬浮球版 1.1.0）

Windows 蓝紫渐变悬浮球与托盘小工具。复用本机 Codex 的 ChatGPT 登录，显示各额度池的剩余比例、重置时间与倒计时。

社区制作，非 OpenAI 官方产品。支持每轮任务用量和缓存命中率统计。本文截图使用演示数据。

**[下载 Windows 便携版](https://github.com/loverelic0-wq/codex-quota-monitor/releases/latest)** · [项目源码](https://github.com/loverelic0-wq/codex-quota-monitor) · [更新记录](CHANGELOG.md)

在发布页下载 `CodexQuotaMonitor-Windows-v1.0.0.zip`，先完整解压到固定文件夹，再双击 `CodexQuotaMonitor.exe` 或 `Start.cmd`。不要直接在压缩包内运行。程序无需安装 Python 或 Node.js。

如果下载的是 GitHub 的 Source code 源码包，其中没有 EXE；双击 `Start.cmd` 会先调用 Windows 自带的 .NET Framework C# 编译器，再启动程序。

## 使用

1. 双击本目录的 `CodexQuotaMonitor.exe`，默认在屏幕右侧显示一个蓝紫渐变圆形悬浮球，不打开大面板。
2. 默认每 **5 分钟**更新一次；剩余 **20% 或以下**时发送 Windows 托盘通知。
3. 单击悬浮球展开深色小窗，单击小窗空白区域或右上角减号收起；离开窗口后保持展开。点击小窗的「额度详情」或「任务用量」进入完整面板。
4. 右键悬浮标签或托盘图标，选择「退出监控」才会完全退出。

需要桌面快速启动时，在程序文件夹运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Create-DesktopShortcut.ps1
```

快捷方式指向解压目录，创建后请保留该目录。更新程序前先从托盘退出，再解压新版；原设置和任务历史保存在独立的本机数据目录。

## 贴边悬浮窗

- 收起窗口约 **80 × 80** 像素，内含 **72 × 72** 像素圆球；展开约 **248 × 184** 像素，随系统缩放调整。悬浮窗保持置顶，展开不会抢走正在使用的窗口焦点。
- 圆形悬浮球采用平滑透明边缘、柔和阴影与蓝紫渐变；展开面板采用深色圆角卡片。
- 与 Mac 版采用相同配色：悬浮球从 **#4D7CFE** 渐变到 **#7A5CFF**，白色百分比；详情采用 **#1E2028** 深灰背景、**#E8E8F0** 文字和 **#7A9BFF** 强调色。低额度判断和提醒照常工作，悬浮球不随剩余额度切换红黄绿。
- 未知额度显示「—」；同步失败保留上次百分比，圆球显示「待更新」，工具提示说明状态，不把未知值当作零。
- 按住标签或小窗的空白区域拖动，松手后吸附到所在屏幕较近的左边缘或右边缘，并收起。会保存屏幕、左右侧和高度；兼容多屏负坐标，位置限制在工作区内以避开任务栏。
- 小窗右上角的刷新按钮手动同步，减号立即收起；下方显示最近一轮主任务的 Token 用量、缓存命中率和两个详情入口。小窗里的 K/M/B 分别代表千/百万/十亿 Token，任务用量面板显示完整数值。
- 右键选择「隐藏悬浮窗」只隐藏标签，后台监控与任务统计继续。托盘中的「显示贴边悬浮窗」可以重新显示；再次启动程序也会恢复收起的标签。
- 大面板的关闭、最小化或「收至托盘」不会隐藏悬浮标签。双击托盘图标仍可直接打开完整面板。



## 每轮任务消耗

点击面板右下方的「任务用量」，或右键托盘选择「查看任务用量」。工具每 **5 秒**检查一次本机任务记录；新的一轮完成后，会弹出本轮 Token 用量摘要。这个检查频率独立于账户额度的刷新频率。

- **一轮**：一次提问到 Codex 本轮结束。同一个任务继续追问，会产生下一条记录。
- **本轮 Token**：直接采用本机 Codex 的 `turn_token_usage`，包含该轮多次模型调用的用量，不只取最后一次回复。
- **会话累计**：采用 `thread_token_usage`，反映该会话截至这一轮的累计用量。
- **明细**：选中记录查看输入、缓存命中、输出、推理和模型。缓存命中已包含在输入中，推理已包含在输出中，不能再次相加；多次调用会反复计入上下文，所以 Token 数可能远大于最终回复字数。
- **子任务**：单独列出，用量不重复计入主会话。完成通知默认只提醒主会话；列表中的子任务不会单独弹窗。
- **历史**：首次启动导入最近 7 天目录中的本机记录，按批次加载；保留最新 200 条完成记录。首次加载、重启或重复读到旧记录，不批量重放通知。较早但仍在使用的任务，通过运行中的文件变化跟踪。
- **延迟与未知**：等待最终用量写入后再通知，通常在完成标记落盘后约 5–15 秒；界面会补齐稍后到达的用量。日志缺失、老版本不提供用量时显示「未知」，不会估算成零。

在任务用量窗口右上角可关闭「每轮完成后提醒」，历史统计仍然继续。该开关与低额度提醒独立。

## 缓存命中率

打开「任务用量」，顶部显示近期汇总，列表和选中记录的明细显示每一轮的命中率。任务完成通知也会附带该轮命中率。

- **每轮命中率 = 缓存命中的输入 Token ÷ 全部输入 Token × 100%**。例如输入 10,000 Token，其中缓存命中 8,000，命中率是 80%。缓存命中已经包含在输入数里，不把两者相加；输出和推理 Token 不参与这个比例。
- **近期汇总 = 有效轮次的缓存命中输入总和 ÷ 有效轮次的输入总和**，按输入量加权，不直接平均各轮百分比。例如 100 输入/50 命中与 900 输入/900 命中，汇总为 95%。
- 范围为本工具当前保留的本机完成记录，最多 200 轮，包括主任务和子任务各自的独立用量；按轮次去重，不累加每行的「会话累计」。这不是整个账户、所有设备或完整历史的命中率。
- 只有输入和缓存命中数都有效、输入大于 0 的轮次进入汇总。未知或异常字段、零输入会分别显示排除数量；全部缺失或无有效输入时显示「未知」，不视为 0%。迟到数据会自动更新相应轮次和汇总。

命中率表示输入 Token 被缓存复用的比例，不等于请求命中率，也不直接代表订阅额度或费用节省比例。



Token 统计不能精确换算为某一任务独占的订阅额度百分比或金额；多个任务可能同时使用账户额度。当前版本只把已验证的本机 `task_complete` 标记作为结束依据，不把暂时空闲当作任务完成；异常退出、中断或无本机日志的云端任务不保证有记录。

可以在完整面板修改刷新频率（1 / 5 / 10 / 15 分钟）、提醒阈值（1–90%）、通知开关和大窗口置顶。重复启动会恢复已有的收起标签，不会创建多个监控进程。电脑重启后需要重新打开本工具；本版不修改开机启动项。

兼容原来的后台启动命令；它也会按已保存的设置显示悬浮标签：

```powershell
.\CodexQuotaMonitor.exe --tray
```

## 显示与提醒

- 托盘数字：主 Codex 额度池中，各已知窗口剩余比例的最小值；小数向下取整，面板保留小数。
- 面板：按接口真实返回的数据展示 Codex、Spark、备用额度及其他额度池。周期按实际分钟数显示，不固定假设存在「5 小时 + 7 天」两个窗口。
- 缺失数据：显示未知或不显示该窗口，不当作 0% 或 100%。没有重置券字段时显示「未提供」。
- 重置时间：使用电脑本地时区。倒计时结束后等待接口确认新额度，不自行改成满额。
- 提醒：所有额度池的任一已知窗口达到阈值时提醒；同一窗口持续偏低不会每次刷新都通知，恢复或进入新周期后会重新提醒。重启工具后会重新检查。系统「请勿打扰」等设置可能隐藏通知。
- 同步失败：面板标明「上次结果 · 待更新」，托盘改为灰色，保留上次成功时间并自动重试（1、2、4、8、15 分钟，最多 15 分钟）。网络恢复后自动恢复正常频率。错误文字被截断时，鼠标悬停可查看完整说明。

这里显示的是账户共享的使用额度百分比，不能换算成精确剩余 token 或请求次数。

## 环境与数据

适用于 Windows 10 / 11、.NET Framework 4.8，以及已安装并登录 ChatGPT 账户的 Codex。无需额外安装 Python、Node.js 或付费 API Key。仅使用 API Key 登录时，可能无法读取 ChatGPT 订阅额度。

程序自动寻找本机 Codex 桌面版原生 CLI，找不到时尝试 npm 安装中的原生 CLI。通过官方 App Server 的 stdio 接口发送 `initialize`、`initialized`、`account/rateLimits/read`。不创建模型任务，不执行重置或购买，不读取或复制凭据文件。

不启动 Web 服务、不占用监听端口。读取完成或超时后关闭自己启动的 Codex 查询进程。账户 ID 仅用于内存中的额度提醒去重；程序不保存账户额度历史、认证 token 或 cookie。

设置写入 `%LOCALAPPDATA%\CodexQuotaMonitor\settings.json`；任务历史写入同目录的 `task-usage.json`，只保存任务标题、任务/轮次 ID、时间、模型和数值用量，不复制聊天正文或工具输出。任务记录默认从 `%USERPROFILE%\.codex\sessions`、运行中的归档变化及 `session_index.jsonl` 只读获取；设置了 `CODEX_HOME` 时使用该目录。

接口和安装路径依赖 Codex 版本，未来更新可能需要适配。接口参考：[OpenAI Codex App Server](https://learn.chatgpt.com/docs/app-server)。

原 1.0.0 版在 Windows 11 x64、.NET Framework 4.8、本机 Codex CLI 0.153.4 环境验证。本次 1.1.0 外观版在 Mac 上交叉编译；Windows GUI 与系统通知尚未在本机实测。其他 Codex 安装布局和未来日志格式可能需要适配。

## 源码与验证

- `src/Program.cs`：Windows 面板、托盘、刷新、设置和进程生命周期。
- `src/CodexClient.cs`：本机 CLI 发现、stdio 通信、超时与取消。
- `src/UsageModel.cs`：额度解析、周期显示、提醒去重。
- `src/TaskUsageParser.cs`：本机任务完成事件、独立轮次用量、复制历史过滤。
- `src/TaskUsageMonitor.cs`：增量读取、历史与完成提醒去重。
- `src/TaskUsageForm.cs`：任务历史列表与明细。
- `src/CacheUsageStatistics.cs`：每轮缓存命中率、输入量加权汇总、未知数据处理和轮次去重。
- `src/FloatingQuotaForm.cs`：不抢焦点的单击展开、收起、拖动、贴边悬浮球。
- `src/FloatingQuotaVisual.cs`：四倍分辨率绘制后缩小，生成带平滑透明边缘的标签与展开面板。
- `src/LayeredWindowSurface.cs`：将预乘 Alpha 图像提交给 Windows 分层窗口，保留圆角透明过渡。
- `src/EdgeDock.cs`：屏幕工作区定位及额度颜色规则。
- `tests/`：合成数据的额度与提醒测试；不读取真实账号。

重新编译：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

运行测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\Run-Tests.ps1
```

需要排查本机连接时，可以生成不含账户 ID 或凭据的诊断报告；报告包含额度数字、时间和 Codex 程序路径：

```powershell
.\CodexQuotaMonitor.exe --diagnose "$PWD\diagnostic.json" --render "$PWD\preview.png"
```

追加 `--with-tasks` 会在报告目录的 `task-diagnostic-data` 中创建隔离的任务历史并检查本机记录；追加 `--render-tasks "$PWD\tasks-preview.png"` 可以保存任务面板截图。任务截图含标题与用量，分享前请检查内容。

追加 `--render-floating "$PWD\floating"` 会保存 `floating-collapsed.png` 与 `floating-expanded.png`，用于检查悬浮窗外观。

删除本目录即可移除程序；设置可另行删除 `%LOCALAPPDATA%\CodexQuotaMonitor`。请先从托盘退出。
