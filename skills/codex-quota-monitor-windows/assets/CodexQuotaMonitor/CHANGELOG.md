# 1.1.0 蓝紫悬浮球外观同步

- 圆形悬浮球 72px，蓝紫渐变 #4D7CFE → #7A5CFF，与 Mac 版一致。
- 详情、任务列表和设置采用深色背景、浅蓝强调色。
- 点击展开／收起，移开指针后保持展开；保留 Windows 多屏贴边、托盘、任务通知及额度查询。
- 原始采集、凭据边界和统计口径不变。

# 更新记录

## 1.0.0 · 2026-09-11

首次公开发布。

- Windows 贴边悬浮窗和托盘；悬停展开、离开收起、拖动吸附与位置记忆。
- 读取账户剩余额度及重置时间，低额度提醒，失败后自动重试。
- 本机每轮任务 Token 用量、独立子任务记录和完成提醒。
- 每轮缓存命中率、最近保留记录的输入量加权汇总，未知和零输入单独统计。
- 平滑透明圆角、轻微渐变、细描边与柔和阴影。
- 解压后双击运行；同时提供源码、一键编译启动和桌面快捷方式脚本。

适用于 Windows 10 / 11、.NET Framework 4.8，以及已安装并使用 ChatGPT 账户登录的 Codex。任务记录只覆盖本机可读日志；不能把单个任务 Token 或缓存命中率换算为独占的订阅额度消耗。
